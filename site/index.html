Leaf: the open document format to replace PDF.

A Leaf file looks the same on every device, like a PDF. But it stays editable, fillable and signable, with no paid software. Anyone can read the code and the spec.

Try Leaf in your browser View source on GitHub

Opens .leaf and .pdf files. It runs in your browser, so nothing is uploaded.

Why replace PDF?

PDF was made for printing. Editing one is painful, and signing one usually means a paid service. Leaf keeps what makes PDF dependable, the same pages everywhere, and adds what it lacks.

  • Edit like a normal document. Change the text and the pages re-flow.
  • Fill and sign without a service. Anyone can check a signature and see whether the file changed.
  • Open to everyone. A Leaf file is a plain ZIP of readable JSON, and the spec is public.
  • Works with PDF. Open a PDF, and export any Leaf file to PDF whenever you need to.

Try it

  1. Open the editorChoose a Leaf or PDF file, or start a new Leaf document.
  2. Click the text to change itSigning, highlighting and forms are in the bar on the left.
  3. Press Save as LeafYou get one file that opens in any web browser with a double-click. Email it to anyone: they can read, fill in and sign it with nothing to install.

Leaf is version 0.1, an early draft. The format may still change, so do not rely on it yet for documents that must stay readable for years. Signatures use demo keys for now, so do not use them for legal signing.

Open source

The code and the format are public. Read them, run your own copy, report a bug or help shape the spec.
